------------------------------------------------------------------------------------------
HOW TO READ THIS FILE
------------------------------------------------------------------------------------------
  Program IDs ....... B-xx  = program from the Bachelor brochure (B-10 is a Master program)
                      M-xx  = MBBS (medicine) program
                      P-xx  = PhD program
                      MA-xx = Master program (from the Master file)
                      L-01  = 6-month Chinese language program
  "City #n of N" .... n-th program located in that city within the same section (names
                      removed, so the number tells programs in the same city apart)
  Values ............ copied VERBATIM from the source (spelling, currency style, typos)
  [CHECK] ........... suspicious / inconsistent value in the source - verify before use
                      (full list in SECTION 13)
  [IMG] ............. text that exists ONLY inside an image in the PDF (not selectable text)
  [AGENCY] .......... service/feature provided by a third-party agency, not the university
                      (agency names & contacts are in SECTION 12)
  [ADDED] ........... information NOT in the source files, added for completeness
  [DERIVED] ......... calculated from numbers in the source, not stated directly
  [University] ...... placeholder where the source text used the university's own name
  CNY = RMB = yuan (Chinese currency).  $ = USD.  Taka = Bangladeshi currency.
